**Cortex 1.1** adds AI that runs on **your own API key**, a **Vault Doctor** that finds and fixes what makes a vault hard to use, and plugins that work properly.

### Download
**`Cortex-1.1.0-portable.exe`** (Windows 10/11, x64) is a single portable file. There is no installer and you don't need admin rights: download it and run it. Your notes stay as `.md` files in `Documents\CortexVault`, and 1.0.0 vaults open as they are.

> **Windows may warn you.** The exe is not code-signed yet, so SmartScreen can show "Windows protected your PC". Click **More info → Run anyway** if you trust this download. SHA-256: `{{SHA256}}`

### New: Synapse, AI with your own key
Open it from the ✨ button in the activity bar (or `Ctrl+P` → "Open Synapse AI"), pick a provider and paste a key:

| Provider | Default model |
|---|---|
| **Anthropic** | `claude-opus-5-5` |
| **OpenRouter** | `openrouter/auto` (any OpenRouter model id works) |
| **NVIDIA NIM** | `meta/llama-3.3-70b-instruct` (any build.nvidia.com model id works) |

- **Summarize** a note.
- **Suggest links**, only to notes that actually exist.
- **Suggest tags**, chosen from the tags you already use.
- **Make flashcards** and send them to Recall.
- **Extract tasks** and send them to TaskFlow.
- **Ask your vault**: the notes that best match your question are sent to the model, and the answer cites them as `[[links]]`.
- **Your key stays private.** It is encrypted with your Windows account (DPAPI) and only ever used by the app's background process. The page that shows your notes never sees the key and still can't connect to the internet.
- **Only what you choose is sent.** Each request carries the note you ran Synapse on (or, for *Ask your vault*, the few best-matching notes), and it goes only to the provider you picked.

### New: Vault Doctor
Open it from the ♥ button in the activity bar.
- **Health score**: the share of your notes with no issues.
- **Issue lists**: broken links, orphan notes (nothing links to them and they link nowhere), stubs (very short notes) and duplicate names.
- **One-click fixes**:
  - Create a missing note. It never overwrites an existing one.
  - Jump to the note that has the problem.
  - Ask Synapse to suggest links for an orphan.

### Fixed and improved
- **Recall**:
  - Schedules reviews with real **SM-2** spaced repetition.
  - A card you answer with "Again" comes back later in the same session.
  - Card text can no longer inject HTML.
- **TaskFlow**: the **Edit**, **Delete** and per-column **+ Add** buttons work.
- **All plugins**: a panel closes cleanly instead of piling up hidden copies.
- **DailySync**: the "Create as Note" draft is no longer lost on the second try.
- **App icon**: the app now has its own icon.

### Known limitations
- Windows only.
- AI replies appear all at once, not word by word.
- There is no local-model (Ollama) option yet.
- DataForge, DailySync and FocusPulse are still early.
- The exe is not code-signed, and there is no auto-update.
